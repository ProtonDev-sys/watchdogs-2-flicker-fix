WATCH DOGS 2 FLICKER FIX

Installs Luma's Watch Dogs 2 mod, which fixes the shadow flickering.

INSTALL
  1. Extract this ZIP.
  2. Close the game and run Install.cmd.
  3. Pick your Watch Dogs 2 folder (the one containing bin\WatchDogs2.exe).
  Press F10 in-game to open the Luma/ReShade menu.

The installer downloads the official Luma latest-722 release (~36 MB) and
checks its SHA-256 before installing anything. If a mod file is already
there, it stops instead of overwriting it. Online play works.

UNINSTALL
  Close the game, run Uninstall.cmd and pick the same folder.
  Your old ReShade.ini is restored. Backups stay in
  bin\WD2-Luma-Installer-Backup. Delete or move that folder before reinstalling.

If you get "access denied", run Install.cmd as administrator.
